01 / VERSION CONTROL

Git keeps track of your work.

Git records changes to files so you can experiment, collaborate, and safely return to an earlier version.

↳

Working directory

Edit your project files on your computer.

＋

Staging area

Select the changes you want in your next snapshot.

Repository

Save a commit in your project's history.

Essential Git commandsTERMINAL
# Start tracking a project
git init
# Check what changed
git status
# Stage changes and save them
git add .
git commit -m "Add home page"
# View previous commits
git log --oneline
Remember: Git tracks versions locally; GitHub is a platform where you can host and collaborate on Git repositories.
